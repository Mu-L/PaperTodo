02 / 胶囊模式Capsule mode

桌面要清净，就把纸折成胶囊。

Clear the desktop.Fold papers into capsules.

纸片没有消失，只是收进当前屏幕的边缘队列。鼠标靠近时滑出，点击便回到原来的展开状态；也可以直接拖到另一块屏幕。

The paper is not gone; it joins the edge queue on the current screen. Hover to reveal it, click to restore it, or drag it directly to another display.

  • 自动加入左右边缘队列，悬停滑出Joins a left or right edge queue; hover to reveal
  • 点击恢复纸片，也可记住展开位置Click to restore, with an option to remember position
  • 主胶囊一键收起队列，多屏之间直接拖动Fold a queue from its master capsule; drag across displays

03 / Markdown 渲染Markdown rendering

Markdown，三种阅读密度。

Markdown,three reading levels.

原文完整保留标记；基础模式给语法加上轻量高亮；增强模式进一步整理标题、列表、强调和分隔线。三档会自动轮播，手动选择后停在你的选择。

Raw keeps every mark. Basic adds lightweight syntax highlighting. Enhanced further refines headings, lists, emphasis, and rules. The demo cycles automatically and pauses when you choose a mode.

04 / 脚本胶囊Script capsules

写下 !p，折成脚本胶囊。

Write !p.Fold into a script capsule.

在笔记首行写 !p 或 !power，余下内容就作为 PowerShell 脚本。折成闪电胶囊后，左键运行、右键回到笔记编辑；!pf / !powerf 可投递到常驻进程。

Put !p or !power on the first line and the rest becomes a PowerShell script. Fold it into a lightning capsule: left-click to run, right-click to edit. Use !pf / !powerf for the persistent process.

  • 脚本仍是一张普通文本笔记，不需要另一套管理器The script stays a plain text note—no separate manager
  • 可优先使用 PowerShell 7，并复用常驻进程Prefer PowerShell 7 and reuse a persistent process
  • 关联到待办后，可按需从任务行直接运行Link it to a todo and optionally run it from the task row

更多特性

More features

让桌面上有几张安静、可用、不打扰人的纸。

A few quiet, useful papers that don't get in the way.

纸片优先

Paper-first

没有主窗口，没有管理器。每张纸都是独立窗口，想记就写，完成就勾，位置和内容自动保存。

No main window, no manager. Each paper is an independent window—write, check off, auto-saved.

多屏支持

Multi-screen

每个屏幕边缘有独立队列，拖动单个胶囊就能换边或挪到其他显示器。主胶囊一键收起或展开全部。

Independent queues per screen edge. Drag a capsule to switch sides or move to another display. Master capsule folds or expands all.

待办关联笔记

Link notes

待办项可以关联笔记纸，从任务行直接打开相关笔记。关联脚本后，还可按需开启「点击直接运行」。

Todo items can open linked note papers directly. For linked scripts, optionally enable direct execution from the task row.

本地图片

Local images

笔记纸支持插入本地图片，粘贴、拖入或菜单选图。图片保存在本地 LMDB 文件里。

Insert local images in note papers via paste, drag, or menu. Images saved in local LMDB file.

全局快捷键

Global hotkeys

可以绑定显示、隐藏、切换、新建待办、新建笔记的全局快捷键。支持左右队列 1–9 快捷打开边缘胶囊。

Bind global hotkeys for show, hide, toggle, new todo, new note. Supports left/right queue 1–9 for edge capsules.

WPF 原生实现

Native WPF

纯 WPF 原生实现，不是 Electron 或 Web 套壳。启动快，内存占用低，支持高 DPI 和触控板手势。

Pure WPF, not Electron or web wrapper. Fast startup, low memory, high-DPI and touchpad gestures supported.

Q / A

常见问题

Common questions

免费吗？需要联网吗？Is it free? Does it need internet?

免费使用，源码公开。日常使用不需要联网，也不需要注册账号。数据保存在本地，笔记图片存在单个 LMDB 文件里。

Free to use, with source available. No internet or account needed. Data saves locally; note images stay in a single LMDB file.

支持哪些 Windows 版本？Which Windows versions are supported?

支持 Windows 10 与 Windows 11 x64。自包含版本无需另装 .NET Runtime。

Windows 10 and Windows 11 x64. The self-contained build needs no separate .NET installation.

数据如何备份和迁移？How do I back up or move my data?

退出 PaperTodo 后复制整个程序文件夹即可。纸片内容、设置和笔记图片会一起带走，数据在 data.json 和 note-assets.lmdb 里。

Exit PaperTodo and copy the whole app folder. Papers, settings, and note images move together in data.json and note-assets.lmdb.

为什么首次运行会出现 SmartScreen 警告？Why does SmartScreen appear on first run?

项目暂未购买商业代码签名证书。选择“更多信息 → 仍要运行”即可，每台电脑通常只需确认一次。可以在 GitHub Release 页面校验文件哈希。

The project does not yet use a commercial code-signing certificate. Choose “More info → Run anyway.” You usually only need to confirm once per PC. Verify file hashes on the GitHub Release page.

可以自定义主题和字体吗？Can I customize themes and fonts?

提供暖纸、墨、林、霞四套配色方案，支持跟随系统或手动切换浅色/深色主题。可以选择系统默认、微软雅黑、等线，或放入自定义字体文件（papertodo.ttf / papertodo.otf）。

Four color schemes: Warm, Ink, Forest, Rosy. Supports system theme or manual light/dark toggle. Choose system default, Microsoft YaHei, DengXian, or drop in custom fonts (papertodo.ttf / papertodo.otf).

支持全局快捷键和启动参数吗？Does it support global hotkeys and launch parameters?

可以在设置里为显示、隐藏、切换、新建待办、新建笔记绑定全局快捷键；还支持左右队列 1–9 快捷打开边缘胶囊。也可以用启动参数（--show / --hide / --toggle / --new-todo / --new-note）配合外部快捷键工具或脚本调用。

Bind global hotkeys in settings for show, hide, toggle, new todo, new note; plus left/right queue 1–9 for edge capsules. Launch parameters (--show / --hide / --toggle / --new-todo / --new-note) work with external hotkey tools or scripts.
